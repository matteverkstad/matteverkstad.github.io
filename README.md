# Matteverkstad

Träna matematikens grunder, med nya uppgifter varje gång:

- **Positionssystemet**
- **Huvudräkning**
- **Klocka och tid**
- **Enheter**

Filer: `index.html`, `grundtraning.js` (övningarna), `stil.css`, `bilder/`, `manifest.webmanifest` + `sw.js` (installerbar app som fungerar utan internet).
Byggs från Mattekompassens Matematikverkstad. Publiceras med GitHub Pages från grenen `main`.
